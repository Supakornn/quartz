# Quartz Features

This directory contains comprehensive documentation for all the features available in Quartz 4. Each feature is designed to enhance your digital garden or website with minimal configuration.

## What you'll find here

Complete documentation for Quartz's extensive feature set:

### Core Features

- **[[full-text search]]** - Blazing fast search powered by Flexsearch
- **[[graph view]]** - Interactive visualization of note connections
- **[[backlinks]]** - Automatic discovery and display of page relationships
- **[[wikilinks]]** - Support for wiki-style linking between notes
- **[[popover previews]]** - Hover previews of linked content

### Content Features

- **[[Obsidian compatibility]]** - Full compatibility with Obsidian vaults
- **[[Latex]]** - Mathematical notation and equation support
- **[[Mermaid diagrams]]** - Create flowcharts and diagrams in markdown
- **[[syntax highlighting]]** - Code highlighting for multiple languages
- **[[callouts]]** - Beautiful callout boxes for important information

### Navigation & Discovery

- **[[explorer]]** - File tree navigation component
- **[[table of contents]]** - Automatic TOC generation
- **[[breadcrumbs]]** - Show current page location
- **[[folder and tag listings]]** - Organize content by folders and tags
- **[[recent notes]]** - Display recently modified content

### Publishing & Sharing

- **[[RSS Feed]]** - Automatic RSS feed generation
- **[[social images]]** - Auto-generated social media preview images
- **[[comments]]** - Integrate discussion systems
- **[[private pages]]** - Control content visibility

### Technical Features

- **[[SPA Routing]]** - Lightning-fast page navigation
- **[[darkmode]]** - Built-in dark/light theme switching
- **[[i18n]]** - Internationalization support
- **[[Docker Support]]** - Containerized deployment options
