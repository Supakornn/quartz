# Documentation Images

This directory contains all the images, screenshots, and visual assets used throughout the Quartz documentation.

## What you'll find here

Visual assets that support the documentation:

### Image Types

- **Screenshots** - UI examples and interface demonstrations
- **Diagrams** - Technical illustrations and flow charts
- **Preview Images** - Examples of features and components in action
- **Configuration Examples** - Visual guides for setup processes

### Current Assets

The images in this directory include:
- Quartz layout examples for desktop, tablet, and mobile views
- Social media preview image templates (light and dark themes)
- GitHub setup and configuration screenshots
- DNS and hosting configuration examples
- Feature demonstrations and UI previews

### Usage

These images are referenced throughout the documentation using standard markdown syntax:
```markdown
![Alt text](images/filename.png)
```

### File Organization

Images are organized by:
- Feature demonstrations
- Setup and configuration guides
- UI/UX examples
- Technical diagrams

All images are optimized for web viewing and documentation purposes, ensuring fast loading while maintaining visual clarity.

These visual aids help make the documentation more accessible and easier to follow, especially for complex setup procedures and feature explanations.
