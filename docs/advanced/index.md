# Advanced Quartz Documentation

This section contains advanced documentation for Quartz 4, covering deeper technical topics for developers who want to understand how Quartz works internally or extend its functionality.

## What you'll find here

Advanced topics for experienced users and developers:

### Current Documentation

- **[[architecture]]** - Deep dive into Quartz's internal architecture, build process, and how the static site generator works
- **[[creating components]]** - Complete guide for creating custom Quartz components using TypeScript and JSX
- **[[making plugins]]** - How to develop custom plugins to extend Quartz's functionality
- **[[paths]]** - Understanding Quartz's path resolution system and how URLs are generated

### Who this is for

This documentation is designed for:
- **Developers** who want to understand Quartz's internals
- **Plugin creators** building extensions for the Quartz ecosystem
- **Component developers** creating custom layouts and functionality
- **Contributors** who want to contribute to Quartz development
- **Advanced users** who need to debug or troubleshoot complex setups

### Prerequisites

To work with these advanced topics, you should have:
- Experience with JavaScript and TypeScript
- Understanding of Node.js and npm/yarn
- Familiarity with React/JSX concepts
- Knowledge of static site generators

### Getting deeper

These guides go beyond basic configuration and usage to help you:
- Understand the build pipeline and transformation process
- Create reusable components for your specific needs
- Develop plugins that extend core functionality
- Troubleshoot complex issues
- Contribute to the Quartz project

If you're just getting started with Quartz, you might want to check out the main documentation first before diving into these advanced topics.
